# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in goDl, please report it responsibly
by emailing the maintainers directly rather than opening a public issue.

Contact: Open a [private security advisory](https://github.com/fab2s/goDl/security/advisories/new) on GitHub.

We will acknowledge receipt within 48 hours and aim to provide a fix or
mitigation within a reasonable timeframe depending on severity.
